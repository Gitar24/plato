# Plato Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o pet no Plato: balão preto e simples, mascote mais fino que olha para os lados, personalidade de filósofo irônico e cínico.

**Architecture:** O sprite perde os olhos e ganha pernas finas; `pet/main.py` desenha os olhos por cima, na posição dada por uma função pura. A personalidade é o texto `DEFAULT_PERSONA` do serviço.

**Tech Stack:** Python, PySide6, Docker Compose, `unittest`.

**Spec:** `docs/superpowers/specs/2026-11-24-plato-design.md`

## Global Constraints

- Nome: `Plato`. Português do Brasil, sem gírias.
- Fundo preto `#000000`, texto branco `#ffffff`, borda cinza 1 px `#555555`, fonte padrão do sistema.
- Azul do corpo `#6c9aff`, olhos `#0a0a0f`, sprite 57x41, `SPRITE_SCALE = 3`.
- A pasta não é um repositório git: não há commits. Antes de editar, copiar `pet.png`, `main.py` e `llm.py` com sufixo `.original` antes da extensão.
- Testes: `%USERPROFILE%\.local\venvs\plato\Scripts\python.exe -m unittest discover -s tests -v`, na raiz do projeto.

## Review Focus

- Notícia de tragédia: sem ironia nem cinismo sobre vítimas.
- Fala longa: o balão cresce e o texto não é cortado.
- Pet falando (flutuando): os olhos acompanham o corpo.
- Olhar para os lados: os olhos nunca saem da cabeça.
- Serviço reconstruído: continua em `production`.
